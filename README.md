# ТБШ — Творческая мастерская по переработке одежды ♻️

🔗 Сайт проекта: https://tihonbest.github.io/tbcha/

## О проекте

ТБШ — это проект о творческом переосмыслении старой одежды. Мы показываем, как вещи, которые уже не носят, могут получить вторую жизнь и превратиться в уникальные, современные и стильные предметы гардероба.

Наша цель — объединить творчество, моду и ответственное отношение к окружающей среде, доказав, что у старых вещей есть потенциал для нового будущего.

## ✨ Что есть на сайте

* Главная страница — знакомство с проектом ТБШ.
* О проекте — наша идея, цели и история.
* До и после — примеры преображения одежды.
* Мерч — коллекция вещей и изделий проекта.
* Педагоги — информация о преподавателях и наставниках.
* Новости — события и обновления проекта.
* Контакты — информация для связи с нами.

## 🎨 Особенности

* Современный визуальный стиль.
* Адаптация для разных размеров экранов.
* Анимации и интерактивные элементы.
* Акцент на повторном использовании одежды и творческом подходе к моде.

Проект создан с использованием веб-технологий:

* HTML5 — структура страниц.
* CSS3 — оформление, адаптивность и анимации.
* JavaScript — интерактивность и динамические элементы.
* GitHub Pages — публикация сайта.

Сайт опубликован с помощью GitHub Pages и доступен по ссылке:
